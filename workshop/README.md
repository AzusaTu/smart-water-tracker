## 🕒 推薦課程時間表 (Syllabus)

```text
09:00 - 09:30   學員報到、WiFi 連線測試、環境確認
09:30 - 10:30   【模組一】IoT 稱重物理原理與無焊組裝
                - 應變規惠斯登電橋原理
                - HX711 24-bit ADC 訊號採集
                - 免焊接快速插拔組裝
10:30 - 12:00   【模組二】動態濾波與兩步自動校準演算法
                - 滑動平均濾波去噪
                - 一鍵去皮 (Tare) 與已知重量兩步校準
                - ESP32 NVS Flash 斷電記憶存取
12:00 - 13:00   午休時間 / 茶點交流
13:00 - 14:15   【模組三】水杯智慧狀態機實作
                - 拿起、放下、喝水判定 (Delta Volume 計算)
                - 加水辨識與空杯防呆
                - 板載 LED 燈效回饋
14:15 - 15:45   【模組四】Web Bluetooth (BLE) 實作與 PWA 儀表板
                - 免裝 App！瀏覽器 Web Bluetooth API 原生直連
                - GATT 服務與 Characteristic 讀寫通訊
                - 現代化波浪水位視覺化與 Chart.js 圖表
15:45 - 16:30   【模組五】Webhook 智慧聯網推播與智慧家庭整合
                - Discord / Telegram / Home Assistant Webhook 串接
16:30 - 17:00   成果展示、一對一除錯驗收、大合照與 Q&A
```
